│                          🎉 ¡BIENVENIDO!                                     │
└──────────────────────────────────────────────────────────────────────────────┘

Este es un sistema completo para gestionar personas y controlar sus comidas
diarias (desayuno, almuerzo y cena) con registro automático de fecha/hora.

┌──────────────────────────────────────────────────────────────────────────────┐
│                      ⚡ INSTALACIÓN RÁPIDA                                   │
└──────────────────────────────────────────────────────────────────────────────┘

1. Instalar dependencias:
   npm install

2. Ejecutar:
   npm run dev

3. Abrir navegador:
   http://localhost:5173

¡Listo! El sistema funcionará con LocalStorage (sin configuración).

┌──────────────────────────────────────────────────────────────────────────────┐
│                      ☁️ USAR CON SUPABASE (OPCIONAL)                        │
└──────────────────────────────────────────────────────────────────────────────┘

Para guardar datos en la nube:

1. Lee: INSTALACION_RAPIDA.md (opción 2)
2. O lee: CONFIGURAR_SUPABASE.md (guía completa)

┌──────────────────────────────────────────────────────────────────────────────┐
│                      ✨ NUEVAS CARACTERÍSTICAS                               │
└──────────────────────────────────────────────────────────────────────────────┘

✅ Nombre completo (en lugar de nombre y apellido separados)
✅ Nombre personalizado para cada comida
✅ Registro automático de fecha/hora de entrega
✅ Borde rojo en comidas con personas pendientes
✅ Integración con Supabase (PostgreSQL en la nube)
✅ Exportación mejorada con horarios
✅ Modo fallback con LocalStorage

MODO LOCAL (Por defecto):

  • Datos en el navegador (LocalStorage)

┌──────────────────────────────────────────────────────────────────────────────┐

Tablas:
  • personas          - Personas registradas
  • comidas           - Comidas creadas
  • asistencias       - Registro de quién comió

Vistas:
  • vista_estadisticas_comidas    - Estadísticas agregadas
  • vista_detalle_asistencias     - Detalle completo

Funciones:
  • crear_comida_con_asistencias  - Crear comida + asistencias
  • set_fecha_hora_entrega        - Registrar hora automáticamente

┌──────────────────────────────────────────────────────────────────────────────┐
│                      🚀 PRIMEROS PASOS                                       │
└──────────────────────────────────────────────────────────────────────────────┘

1. INSTALAR:
   npm install

2. EJECUTAR:
   npm run dev

3. USAR:
   • Pestaña "👥 Personas" → Agregar personas
   • Pestaña "📋 Comidas" → Crear comida
   • Clic en personas → Marcar asistencia
   • Ver estadísticas en tiempo real
   • Exportar a TXT cuando quieras

4. OPCIONAL - CONFIGURAR SUPABASE:
   • Lee CONFIGURAR_SUPABASE.md
   • Ejecuta supabase-schema.sql
   • Configura .env
   • Reinicia el servidor

┌──────────────────────────────────────────────────────────────────────────────┐
│                      ⚠️ IMPORTANTE                                           │
└──────────────────────────────────────────────────────────────────────────────┘

• El archivo .env NO debe subirse a Git (ya está en .gitignore)
• Exporta regularmente a TXT para tener respaldo
• En modo Local, los datos son específicos de cada navegador
• En modo Supabase, los datos están en la nube
