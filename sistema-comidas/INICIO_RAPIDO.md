# 🚀 Inicio Rápido

## ⚡ 3 Pasos para Empezar

### 1️⃣ Instalar
```bash
npm install
```

### 2️⃣ Ejecutar
```bash
npm run dev
```

### 3️⃣ Abrir
Abre tu navegador en: `http://localhost:5173`

---

## 📖 Primeros Pasos

### Paso 1: Registra Personas
1. Ve a la pestaña **"👥 Personas"**
2. Escribe un nombre y apellido
3. Haz clic en **"➕ Agregar Persona"**
4. Repite para agregar más personas

### Paso 2: Crea una Comida
1. Ve a la pestaña **"📋 Comidas"**
2. Selecciona el tipo: **Desayuno 🌅**, **Almuerzo ☀️** o **Cena 🌙**
3. Haz clic en **"➕ Crear"**

### Paso 3: Registra Asistencia
1. Haz clic en cada persona para marcar si comió
2. Verde ✅ = Comió
3. Gris ⏳ = Pendiente

### Paso 4: Exporta los Datos
1. Haz clic en **"💾 Exportar a TXT"**
2. Se descargará un archivo con todo el historial

## 🆘 ¿Problemas?

**No se guardan los datos:**
- Verifica que LocalStorage esté habilitado en tu navegador

**Error al instalar:**
- Ejecuta: `npm cache clean --force`
- Luego: `npm install`

**La página no carga:**
- Verifica que el puerto 5173 esté libre
- Cierra otros servidores de desarrollo
